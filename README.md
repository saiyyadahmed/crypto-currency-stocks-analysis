# Crypto Currency Dashboard

Interactive Cryptocurrency Market Dashboard built in **Microsoft Power BI**.

## ✨ Features

- Real-time crypto metrics (Bitcoin, Cardano, Dogecoin, etc.)
- Historical Market Cap Trend (Area Chart - Jan to Jul 2021)
- Key KPI Cards:
  - 24h Volume: **$28.77B**
  - High: **$0.03K**
  - Average: **$0.00K**
  - Low: **$0.02K**
  - Total Market Cap: **$645.57B**
- Sleek dark theme with interactive filters

## 🛠 Tech Stack

- **Power BI Desktop**
- DAX Measures
- Power Query
- Custom Visuals

## 🚀 How to Use

1. Download the `.pbix` file
2. Open with **Power BI Desktop**
3. Refresh data (if connected to API)
